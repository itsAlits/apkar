# Direktori Model 3D

Tempatkan file model 3D Anda di folder ini (misalnya `model.glb`, `character.glb`, dll).

### Format yang didukung:
- `.glb` / `.gltf` (Sangat direkomendasikan untuk AR mobile)
- `.obj`

### Cara menghubungkan:
Setelah file model ditaruh di sini, model dapat langsung dimuat ke widget AR overlay atau viewer (`o3d` atau `model_viewer_plus`).
